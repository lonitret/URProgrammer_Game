# You're a Programmer! 🎮

A 2D Unity/C# game prototype about the everyday life of a programmer.

## About

You play as a programmer dealing with tasks from your colleagues
while trying to keep your reputation and avoid losing your temper.

## Features

- Quest system
- NPC interactions
- Reputation and anger systems
- Inventory
- 3 NPC quest givers
- 3 quests
- 3 mini-games
- Tutorial
- Interaction hints
- Objective markers
- Main menu and pause menu
- Audio system
- Final result screen

## Tech Stack

- C#
- Unity
- Unity Input System
- ScriptableObjects
- Git
